# 公开发布范围

## 仅公开数学示例

本仓库只提供 75 个示例节点，包括 4 个学科及学段入口、3 个数学模块、40 个题型主题、12 个知识点和 16 个 D6 属性条目。完整分类字典、其余知识点及完整 Excel 均不发布。

页面内嵌数据、图谱 JSON、可读字典和 CSV 保持一致，均仅含这份示例。截图展示同一个数学应用题示例，不使用真实试题或学生照片。

## 不发布的内容

真实题目图片、手写照片、人员标识、业务标注、训练样本、模型权重、非公开提示词、运行日志、存储地址、机器路径、平台身份、凭证及个人联系方式均不发布。

## 检查

`python3 scripts/audit.py` 按固定文件清单扫描公开文件。它会拒绝未经列入清单的文件、符号链接、意外二进制文件，以及匹配凭证、个人联系方式、私有地址和签名链接的文本。

结构校验会检查节点数、公开范围、父级关系和各示例格式的一致性，并拒绝完整字典目录及完整下载目录。截图还需单独查看，确认没有真实题目、个人信息或内部界面。

新增示例时应先审阅具体内容并更新数量和校验，不要将完整内部资料或运行目录复制进仓库。
