从拆书到图谱

将教材的章节结构、知识内容和学习任务分开建模，再通过来源证据与类型约束建立关联。

  1. 教材结构解析按学段、学科、版本、章节组织输入，区分目录、章节摘要与正文材料。
  2. 知识原子化拆解概念、性质、规律、方法与例题中的知识候选，保留上下文。
  3. 来源证据绑定候选记录保留材料定位、证据片段和处理状态，稳定标识支持重复追踪。
  4. 术语归一与版本对齐生成重复、同义和跨版本映射候选，保留来源差异并逐项审核。
  5. 多层知识建模D2/D3 组织任务与主题，D4 维护知识点，D6 独立描述题面和作答属性。
  6. 层次约束与多路检索结合学科、学段、词项匹配与特征检索扩大候选，再校验 ID 和关系。
